## 📌 Présentation

18 captures d'écran (juillet 2026) du **design de référence de WorkTogo (Alo Dowoto)**,
utilisées comme référence visuelle dans les issues du dépôt applicatif. Elles couvrent le
parcours complet :

| Fichiers | Écran |
|---|---|
| `01-home` → `03-choice-modal` | Accueil, tiroir des secteurs, modale de choix client / prestataire |
| `04` → `08` | Inscription prestataire : fournisseur, téléphone, OTP, étape secteur |
| `09` → `13` | Formules d'abonnement et paiement (idle, saisi, en cours, succès) |
| `14-dashboard` | Tableau de bord prestataire |
| `15` → `18` | Inscription client, résultats (chargement, grille, état vide) |

Les images sont au format PNG et peuvent être ouvertes directement depuis GitHub.
